## Запуск проекта

1. **Перейдите в директорию проекта**:
   
   cd <имя_папки_проекта>   

2. **Восстановите зависимости**:
   dotnet restore

3. **Соберите проект**:
   dotnet build

4. **Запустите проект**:
   dotnet run

5. **Откройте Swagger UI** в браузере:
   http://localhost:5105/swagger/index.html

Метод `GetAll` возвращает список событий с поддержкой фильтрации и пагинации.

Метод поддерживает следующие параметры:
   Параметр      | Тип         | Описание                                                                                     | Значение по умолчанию |
 |---------------|-------------|---------------------------------------------------------------------------------------------|-----------------------|
 | `title`       | `string?`   | Фильтрация событий по названию (подстрока). Если `null`, фильтрация по названию не применяется. | `null`                |
 | `from`        | `DateTime?` | Фильтрация событий по дате начала (включительно). Если `null`, не применяется.               | `null`                |
 | `to`          | `DateTime?` | Фильтрация событий по дате окончания (включительно). Если `null`, не применяется.            | `null`                |
 | `page`        | `int?`      | Номер страницы для пагинации.                                                                | `1`                   |
 | `pageSize`    | `int?`      | Количество событий на странице.                                                             | `10`                  |

- Метод принимает параметры для **фильтрации** и **пагинации** и возвращает **`PaginatedResult<EventDto>`**

### Бронирование события
Метод `BookEvent`создаёт бронирование на событие.

**Параметры:**
 | Параметр | Тип   | Описание                     |
 |-----------|-------|------------------------------|
 | `id`      | Guid  | Идентификатор события       |

возвращает **Booking** - модель бронирования.
   Поле          | Тип          | Описание                                      |
 |---------------|--------------|-----------------------------------------------|
 | Id            | Guid         | Уникальный идентификатор                      |
 | EventId       | Guid         | Идентификатор события                         |
 | Status        | BookingStatus| Статус бронирования                           |
 | CreatedAt     | DateTime     | Дата создания бронирования                    |
 | ProcessedAt   | DateTime?    | Дата обработки бронирования                   |


### BookingStatus
Статусы бронирования:
- `Pending` (1): Ожидает обработки.
- `Confirmed` (2): Подтверждено.
- `Rejected` (3): Отклонено.

На данный момент статус `Rejected` (3) не используется. Добавлен с заделом на будущее.

После успешного выполнения запроса придет ответ со статусом 202 Accepted.

После чего бронирование обработается в `BookingWorker`.

## Фоновая обработка

Фоновый сервис `BookingWorker` отвечает за обработку бронирований со статусом `Pending`.
Сервис работает непрерывно в фоновом режиме и выполняет следующие действия:

### Логика работы:
1. **Проверка новых бронирований:**
   - Каждые несколько секунд сервис проверяет наличие новых бронирований со статусом `Pending`.

2. **Обработка бронирования:**
   - Если найдены бронирования в статусе `Pending` - устанавливает статус бронирования на `Confirmed`.
   - Записывает текущую дату и время в поле `ProcessedAt`.

3. **Сохранение изменений:**
   - Обновляет информацию о бронировании в хранилище данных.
   - Логирует успешное завершение обработки.

### Проверка статуса бронирования
Метод GET `/bookings/{id}`
Возвращает текущее состояние бронирования.
Параметры:

**Параметры:**
 | Параметр | Тип   | Описание                     |
 |-----------|-------|------------------------------|
