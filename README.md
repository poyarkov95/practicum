# yandex practicum

## Требования
- [.NET 9.0+ SDK](https://dotnet.microsoft.com/download)
- Любой удобный редактор кода (Visual Studio, VS Code, Rider и т.д.)

---

## Запуск проекта

1. **Перейдите в директорию проекта**:
   
   cd <имя_папки_проекта>   

2. **Восстановите зависимости**:
   dotnet restore

3. **Соберите проект**:
   dotnet build

4. **Запустите проект**:
   dotnet run

5. **Откройте Swagger UI** в браузере:
   http://localhost:5105/swagger/index.html

## Конфигурация
- Порт по умолчанию: `5105` (можно изменить в `Program.cs` или `launchSettings.json`).
- Swagger автоматически настраивается при запуске.

##Обновления

### Описание
Метод `GetAll` возвращает список событий с поддержкой фильтрации и пагинации.

### Изменения
Ранее метод не принимал параметров и возвращал все события без фильтрации и пагинации. Теперь метод поддерживает следующие параметры:
   Параметр      | Тип         | Описание                                                                                     | Значение по умолчанию |
 |---------------|-------------|---------------------------------------------------------------------------------------------|-----------------------|
 | `title`       | `string?`   | Фильтрация событий по названию (подстрока). Если `null`, фильтрация по названию не применяется. | `null`                |
 | `from`        | `DateTime?` | Фильтрация событий по дате начала (включительно). Если `null`, не применяется.               | `null`                |
 | `to`          | `DateTime?` | Фильтрация событий по дате окончания (включительно). Если `null`, не применяется.            | `null`                |
 | `page`        | `int?`      | Номер страницы для пагинации.                                                                | `1`                   |
 | `pageSize`    | `int?`      | Количество событий на странице.                                                             | `10`                  |

 Ранее метод не принимал параметров и возвращал **простой список событий**. Теперь:
- Метод принимает параметры для **фильтрации** и **пагинации**.
- Возвращает **`PaginatedResult<EventDto>`** вместо простого списка.
